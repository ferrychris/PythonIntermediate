Project Title- Todo List 
Description- this script allows users to create, read, update, and delete tasks from a local database. 
Problem Statement- users need a way to manage their daily tasks and keep track of their progress. 
Features
  1. Add Tasks 
  2. View Tasks 
  3. Update Tasks 
  4. Delete Tasks 
Users of the System - students, teachers, professionals, anyone who needs to manage their tasks.
Data to be Stored-  task_id, task_description, task_status, task_todo_date, task_created_date, task_updated_date
Database Table Design-
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  task_description TEXT,
  task_status TEXT,
  task_todo_date TEXT,
  task_created_date DATE,
  task_updated_date DATE
